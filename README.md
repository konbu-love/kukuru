# 九九るMagician

英語の九九を「呪文」にして唱え、魔法を発動する音声ミニゲームです。
英語が苦手な人には、英語の九九が呪文に見える。そこから生まれた企画です。

**あそぶ:** https://konbu-love.github.io/kukuru/

企画記事（Zenn）: https://zenn.dev/konbu_love/articles/3266d6456d7f06

## あそびかた

1. 画面に出た掛け算を、声に出して唱えます（例: 「two times three is six」）。
2. 聞き取れると魔法が発動します。聞き取れなかったら「もう一回！」です。
3. 発音は採点しません。カタカナ発音のままで大丈夫です。

マイクが使えないときは、画面下の入力欄に打ち込む（Gboard などの音声入力でも可）ことで遊べます。

## 魔法のしくみ

- 「左の数字 × 右の数字」の順番で81通りの魔法があります。2×9 と 9×2 は別の魔法です。
- 左の数字が背景色と左から入る魔法、右の数字が上から降る魔法を決めます。
- 同じ数字の式（1×1、9×9 など）は、特別にきらめきます。
- 属性は、1＝火、2＝氷、3＝雷、4＝風、5＝水、6＝森、7＝薔薇、8＝光、9＝闇です。

## 機能

- **カタカナ耳／英語耳**: 音声認識を日本語（カタカナ発音向け）と英語で切り替えられます。
- **段モード**: 1〜9の段を選び、9問を唱えきります。順番どおりとばらばらを選べます。魔女っ子の口調は段ごとに変わります。
- **大魔女の試練（上級）**: 「数あて」（かくれた数字を見抜く）と「魔法あて」（魔法を見て式を当てる）の2種類があります。
- **魔法図鑑**: 81通りの魔法を一覧できます。唱えたことのある魔法は式、まだの魔法は答えの数字だけが表示されます。タップすると、復習（お手本の読み上げ、再挑戦）や、魔法の再生ができます。
- **カットイン**: 魔法発動のたびに魔女っ子が登場します。オン／オフを切り替えられます。

## 動作環境

- スマホの Chrome（Android）を想定しています。音声認識にはインターネット接続とマイクの許可が必要です。
- 図鑑の進み具合などの設定は、お使いのブラウザの中に保存されます。
